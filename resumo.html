Git init

Inicializa um repositório Git na pasta atual. Cria uma pasta oculta chamada .git. Faz com que a pasta passe a ser controlada pelo Git.

Git add

Adiciona arquivos para a área de preparação (Staging Area). O Git "marca" os arquivos que serão salvos no próximo commit.

Git commit

Salva definitivamente as alterações adicionadas com git add. Cria uma versão do projeto.

Git push

Envia os commits do computador para o GitHub (ou outro servidor remoto)

Git pull

Função: Baixa as alterações do GitHub para o computador. Também faz um merge automaticamente.

Git branch

Gerencia as branches (ramificações).

Main

main é a branch principal do projeto. É onde normalmente fica a versão oficial do código.

Git clone

Baixa um repositório inteiro do GitHub.

Git pull

Baixa as alterações do repositório remoto (GitHub) e as aplica automaticamente no seu projeto local.
